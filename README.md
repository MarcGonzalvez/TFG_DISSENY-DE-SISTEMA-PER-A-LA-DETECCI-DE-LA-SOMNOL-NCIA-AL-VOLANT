# TFG_DISSENY-DE-SISTEMA-PER-A-LA-DETECCIO-DE-LA-SOMNOLENCIA-AL-VOLANT
Sistema modular de seguretat activa per detectar la somnolència al volant. Utilitza YOLOv11n en una Raspberry Pi 5 per a visió artificial en temps real, validant les dades mitjançant freqüència cardíaca (ESP32) i telemetria del Bus CAN. Un flux a Node-RED integra els sensors via MQTT.
